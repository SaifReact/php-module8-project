Module 8 Project:Marketing Landing Page Project
Marketing Landing Page Project Documentation
Project Overview
The objective of this project is to create a one-page marketing landing page for a mobile application using HTML and CSS. The structure is provided, and your task is to style it according to the specifications and make it responsive.

Project Structure
The project should contain the following files:

index.html: The HTML structure, which is pre-provided.


styles.css: The custom CSS file for styling the landing page.


Step-by-Step Instructions
1. HTML Structure
Use the provided HTML template for the landing page.


The HTML template is available in the following GitHub repository:


HTML Template Source


2. CSS Styling
Create a styles.css file and apply the following styles:

Basic Reset
Reset all margins and padding.


Set box-sizing to border-box for all elements.


Set a basic global font family and line height.


Header Styles
Set the header background color to white.


Responsive Design
Implement the following media query for screens smaller than 768px to hide the navigation links:

@media (max-width: 768px) {

	.nav-links {

    		display: none;

	}

}
